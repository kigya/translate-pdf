## Current implementation and checks

Production native renderer v10 retains exact source-segment boundary decoding, a shorter isolated document-title instruction and pinned Noto Sans Condensed. Literal markup is preserved; empty or malformed output is rejected. Safe saved transport wrappers can be decoded without inference. A damaged checkpoint receives one durable bounded repair, retaining raw output and history. Layout retries retain conditions, negations, actions and protected values; they do not truncate text or lower the readable font floor.

OCR disagreement resolution requires the same source-owned TOC label and page reference, a verified dot leader and at least 95% raw region overlap in both directions. Only the exact obsolete OCR warning is cleared; other review conditions and historical evidence remain. Android and iOS positive and negative controls pass, including a padded-region false-positive regression.

Android and iOS receipt parsing rejects fractional, string, boolean or null page counts and nonboolean completeness before rebuilding fresh or cached maps. Cache-rebuild regressions retain translated checkpoints. Native page, shard, snapshot and table character-span identities require exact integer JSON and range checks before narrowing. The real-table malformed ownership regression now passes. Each changed linguistic block must create a finite, positive-area target text object before any source mutation; icon tokens and preserved references alone cannot qualify. The real multiline icon-only regression verifies atomic failure. Genuine source-only symbol blocks remain valid.

Renderer v10 orders verified source inline fragments by bounded actual baselines and horizontal coordinates, rather than checkpoint enumeration. Conservative terminal punctuation and wrapped lowercase prose may flow only inside the original paragraph/column, with original glyph content/font/style/linear transforms. Optional compaction cannot reduce font size or horizontal scale. Actual artwork, ownership, container and glyph-ink collision checks remain mandatory, with fixed-layout fallback. It does not permit arbitrary list/legend movement, truncation or a lower readable font floor. Both platform policies invalidate older PDF caches while preserving translations.

## Final review follow-up

Independent iOS review identified callback admission, lossy native count parsing and early stop-write acknowledgement defects after the preceding v10 build receipt. The current fixes restrict callbacks to an already owned active run and bind unique per-run request identifiers and expiration generations. Stop acknowledgement retains ownership and intent until SQLite succeeds, with bounded delayed retries and a second token check inside the serial worker queue. Regressions cover a real transient persistence failure and stale queued retries, using a queue barrier before assertions. Fresh and cached source-preserving native responses use exact integer gates. The first complete run passed 108/111 and exposed three scheduler-integration failures. Adding the processing background mode and a single-component dynamic suffix fixes registration; real scheduler submission returns unavailable (error 1) on the simulator. A production-used request-submission adapter isolates deterministic ownership tests, without fabricating BGTask objects or claiming system execution. Additional review found the same false acknowledgement risk in running-worker PauseSignal/CancelSignal handling. Those paths now share durable acknowledgement with cancellation selected at the locked commit. Worker, retry, UIKit background callbacks, queued requests and attached tasks use exact run tokens, and post-finalization errors cannot write over a resumed run. Independent source review, the current 9-case focused/115-case original XCTest runs and the 108-case iOS 18.6 compatibility run pass. Current-source unsigned device and arm64 simulator Release builds pass. Earlier Release receipts remain historical evidence for their recorded source. Interrupted full-driver attempts produced no test results and are not counted as failures or passes.

Independent static Android processing/export review, including the six new untracked helper files read in full, found no concrete actionable defect. This is code inspection, not physical execution. Three additional native transaction tests verify atomic rejection of stale source checkpoints, mismatched shard geometry and failed final replacement.
